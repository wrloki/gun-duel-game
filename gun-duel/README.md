# 🔫 多人3D枪战

一个用 **Three.js + Node.js + Socket.io** 做的第一人称多人对战小游戏（最多 4 人）。
电脑跑 Node 当服务器，多台手机（或电脑）扫码进同一个房间就能玩。

> 目前进度：**阶段5** —— 4人对战 + 双命制（复活/淘汰）+ 开镜（红点/高倍）+ 大地图 + 高血量。

## 二、安装 Node.js（只需要装一次）

1. 打开官网 https://nodejs.org
2. 下载 **LTS（长期支持版）**，Windows 选 `.msi` 安装包
3. 双击安装，一路"下一步"即可
4. 装完打开命令行（按 `Win + R`，输入 `cmd` 回车），输入下面命令确认成功：

```bash
node -v
npm -v
```

能看到版本号（比如 `v20.x.x`）就说明装好了。

## 三、启动服务器

### 1. 进入项目文件夹并安装依赖（第一次要装）

打开命令行，进入本项目目录（把路径换成你自己的）：

```bash
cd C:\Users\wr201\Desktop\claudecode\gun-duel
npm install
```

> `npm install` 会根据 `package.json` 自动下载 `express` 和 `socket.io`。

### 2. 启动

```bash
node server.js
# 或者
npm start
```

看到下面这行就说明成功了：

```
多人3D枪战 · 服务器已启动！
电脑浏览器打开： http://localhost:3000
```

### 3. 电脑自己先试

浏览器打开 **http://localhost:3000**，输入昵称点"创建房间"进入大厅，点"准备"。再开一个浏览器窗口（或手机）加入同一房间、也点"准备"，房主点"开始游戏"即可开打。用 WASD 移动、点击画面锁定鼠标转视角、左键射击。

## 四、同一 WiFi 下两台手机联机（局域网）

1. 手机和电脑要连 **同一个 WiFi**
2. 查电脑的局域网 IP（命令行输入）：

```bash
ipconfig
```

找到「无线局域网适配器 WLAN」里的 **IPv4 地址**，一般是 `192.168.x.x`。

3. 手机浏览器打开：

```
http://192.168.x.x:3000
```

（把 `192.168.x.x` 换成你查到的 IP）

4. 玩法：
   - 电脑（或手机）点"创建房间"，记下房间号（比如 `AB3C`），也可在"自定义房间号"里手动填一个
   - 另一台手机在首页输入房间号，点"加入房间"（或扫二维码打开后加入）
   - 两人都点"准备"，房主点"开始游戏"开打
   - 一局打完自动回大厅，可再准备、再开一局

> ⚠️ 如果手机打不开，多半是 **Windows 防火墙**拦了端口。第一次运行时系统会弹窗，勾选"允许访问"（专用/公用都勾）。没弹窗的话，手动放行：
> 控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP `3000` → 允许连接。

## 五、外网联机（用 Cloudflare Tunnel，不花钱、不用内网穿透软件）

同一个 WiFi 只能局域网玩。想让**不在身边的朋友**也能扫码进来，用 Cloudflare Tunnel 把本地 3000 端口临时暴露到公网。

### 1. 安装 cloudflared（Windows）

方式一（推荐，用 winget）：
```bash
winget install --id Cloudflare.cloudflared
```

方式二：去 https://github.com/cloudflare/cloudflared/releases 下载 `cloudflared-windows-amd64.exe`，重命名为 `cloudflared.exe`，放到一个能找到的目录。

### 2. 启动隧道（先保证游戏服务器已经在跑）

```bash
cloudflared tunnel --url http://localhost:3000
```

它会输出一行类似这样的公网地址：

```
https://xxxx-xxxx-xxxx.trycloudflare.com
```

### 3. 分享给朋友

把上面的 `https://xxxx.trycloudflare.com` 发给朋友（或让朋友扫首页二维码）。
电脑先"创建房间"，朋友打开网址"加入房间"即可对战。

> ⚠️ 注意：
> - `trycloudflare.com` 是**临时免费**地址，每次启动隧道地址都会变，关掉就失效。
> - 想固定域名需要注册 Cloudflare 账号并配置命名隧道（本文档先不展开）。

## 六、操作方式

| 动作 | 手机 | 电脑 |
|------|------|------|
| 移动 | 左下角虚拟摇杆 | WASD |
| 旋转视角 | 右半屏滑动 | 移动鼠标（先点击画面锁定鼠标） |
| 射击 | 右下角 🔫 按钮 | 鼠标左键 |
| 跳跃 | 右下角 ⬆ 按钮 | 空格 |
| 换枪 | 右下角按钮循环切换 | 1 / 2 / 3 |
| 换弹 | 右下角 ↻ 按钮 | R |
| 开镜 | 右下角 🎯 按钮（该枪支持时显示） | Q |

**武器**：冲锋枪（10伤害/连发/弹匣30发/备弹120/抵肩瞄准）、步枪（18伤害/连发/弹匣30发/备弹90/红点镜）、狙击枪（40伤害/弹匣8发/备弹24/高倍镜）。每把枪独立弹匣+备弹，打空弹匣按 R（手机点 ↻）换弹，从备弹补满弹匣；备弹耗尽则无法继续射击。换弹有短暂冷却，换弹期间不能开枪。总血量 120，每次命中扣固定伤害，需多枪击倒。

**开镜**：冲锋枪=抵肩瞄准（轻微放大，准星收缩成细小瞄准点）；步枪=红点镜（小幅放大）；狙击枪=高倍镜（大幅放大，开镜时移动变慢）。三把枪都支持开镜，手机上 🎯 开镜按钮始终显示。

**生命机制**：一局每人 2 条命，血被打空先复活到随机出生点（自动挑离敌人最远的位置）；第二条命也耗尽则本局淘汰观战，直到只剩最后一人（或最后一方）获胜。

**组队**：大厅里可选【红队】/【蓝队】/【自由混战】。同色=队友（子弹无效，不会误伤）；异色/自由混战=可互相攻击；角色模型按队伍上色（红/蓝/白）。开局前可随时切换，开局后锁定。

> 📱 手机和电脑都支持**竖屏**游玩（屏幕中间有准星），横竖屏都可用。

> 💡 音效是网页用 Web Audio 实时合成的，不需要下载音频文件。首次点击画面后才会出声（浏览器限制）。

## 七、常见问题

- **页面空白 / 3D 不显示？** 需要联网加载 Three.js（用的是 CDN）。确保电脑/手机能上外网，或把 Three.js 下载到本地放到 `public/` 里引用。
- **手机打开特别卡？** 浏览器用 Chrome / Safari 最新版，老手机性能有限。
- **两个人能看到但位置不同步？** 检查双方都在同一个房间号、同一个服务器地址。
- **端口 3000 被占用？** 改 `server.js` 里 `const PORT = process.env.PORT || 3000;` 的数字，或直接 `PORT=8080 node server.js`。
